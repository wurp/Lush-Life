# Lush Life

A gorgeous, full-featured Conway's Game of Life for Android: eight colour themes, glowing trails, pinch-to-zoom, drawing your own cells, eight rule variations, and a library of start patterns — from random kaleidoscope blooms and spaceships to glider guns and working logic gates (NOT, AND, OR), the building blocks that make Life Turing complete.

## Install

On an Android phone, open this link in Chrome and install the file it downloads:
https://github.com/wurp/Lush-Life/releases/download/test-build/app.apk

## Keep building

In the Claude app, open **Code** → **New session**, choose `Lush-Life` above the message box, and describe what to change. (On a computer, [this link](https://claude.ai/code?repositories=wurp/Lush-Life) opens it directly.)
