# Lush Life

A gorgeous, full-featured Conway's Game of Life for Android: eight colour themes, glowing trails, pinch-to-zoom, drawing your own cells, eight rule variations, and a library of start patterns — from random kaleidoscope blooms and spaceships to glider guns and working logic gates (NOT, AND, OR), the building blocks that make Life Turing complete — plus famous machines that compute: Paul Rendell's Turing machine and prime-number generators.

## Install

On an Android phone, open this link in Chrome and install the file it downloads:
https://github.com/wurp/Lush-Life/releases/download/test-build/app.apk

## Keep building

In the Claude app, open **Code** → **New session**, choose `Lush-Life` above the message box, and describe what to change. (On a computer, [this link](https://claude.ai/code?repositories=wurp/Lush-Life) opens it directly.)

## Pattern credits

The Turing machine (Paul Rendell) and the prime machines (Dean Hickerson, Jason Summers and others) come from the pattern collection shipped with [Golly](https://golly.sourceforge.io/). The pi calculator in `patterns-later/` is by Adam P. Goucher.
